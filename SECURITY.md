# Security policy

## Supported versions

Kin Form is pre-1.0. Security fixes are made to the latest published version of
each package (`core`, `react`, `react-devtools`, `validators`) on
[JSR](https://jsr.io/@kin-form); older versions are not backported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately, not through a public GitHub
issue.

Use
[GitHub's private vulnerability reporting](https://github.com/jolleekin/kin-form/security/advisories/new)
for this repository. Include:

- the affected package and version
- a description of the issue and its impact
- steps to reproduce, if available

You should receive an initial response within a few days. Once a fix is
confirmed, it will be released and the report credited (unless you'd prefer
otherwise) in the advisory and the affected package's `CHANGELOG.md`.
